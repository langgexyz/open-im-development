# open-im-hub-proto Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 定义 hub-server 对外暴露的 gRPC 服务（HubService），生成 Go 代码，供 hub-server（server 端）和 open-im-node-server（client 端）共同引用。

**Architecture:** 独立 Go module，仅含 proto 定义和生成的 pb.go 文件。hub-server 实现 gRPC server，node-server 通过 gRPC client 调用。节点鉴权通过 gRPC metadata 传递（`x-node-public-key`、`x-node-timestamp`、`x-node-sig`），等价于原 HTTP Header 方案。

**Tech Stack:** `google.golang.org/protobuf`、`google.golang.org/grpc`、`buf`（代码生成）或 `protoc`

**Spec:** `docs/superpowers/specs/2026-03-20-decentralized-public-account-platform-design.md`

> **独立工程**：`github.com/langgexyz/open-im-hub-proto`，以下路径均基于该仓库根目录。

## Task 2: 编写 hub.proto

**Files:**
- Create: `hub/v1/hub.proto`

HubService 包含四个方法，对应原 HTTP REST 端点：

| gRPC 方法 | 原 HTTP 端点 | 鉴权方式 |
|-----------|-------------|---------|
| `Activate` | POST /node/activate | metadata: `x-activation-code` |
| `Heartbeat` | POST /node/heartbeat | metadata: x-node-sig（节点签名） |
| `SignSession` | POST /node/sign-session | metadata: x-node-sig（节点签名） |
| `PushNotify` | POST /push/notify | metadata: x-node-sig（节点签名） |

节点签名 metadata keys（等价于原 HTTP Header）：
- `x-node-public-key`：节点以太坊地址
- `x-node-timestamp`：Unix 秒级时间戳
- `x-node-sig`：签名 hex

- [ ] **Step 1: 创建目录并编写 proto**

```bash
mkdir -p hub/v1
```

创建 `hub/v1/hub.proto`：

```protobuf
syntax = "proto3";

package hub.v1;

option go_package = "github.com/langgexyz/open-im-hub-proto/hub/v1;hubv1";

// HubService 是 open-im-hub-server 对节点暴露的 gRPC 服务。
// 所有 RPC（Activate 除外）需在 metadata 中携带节点请求签名：
//   x-node-public-key  节点以太坊地址
//   x-node-timestamp   Unix 秒级时间戳（字符串）
//   x-node-sig         签名 hex，签名内容：keccak256("POST\x00/<path>\x00keccak256(body)\x00<timestamp>")
service HubService {
  // Activate 节点注册激活（一次性，用激活码鉴权，无需节点签名）
  // metadata: x-activation-code
  rpc Activate(ActivateRequest) returns (ActivateResponse);

  // Heartbeat 节点心跳保活，告知 hub 节点在线状态
  rpc Heartbeat(HeartbeatRequest) returns (HeartbeatResponse);

  // SignSession 为用户签发 session_sig，同时验证 user_credential
  rpc SignSession(SignSessionRequest) returns (SignSessionResponse);

  // PushNotify 转发离线推送（APNs/FCM）
  rpc PushNotify(PushNotifyRequest) returns (PushNotifyResponse);
}

// --- Activate ---

message ActivateRequest {
  string node_public_key = 1; // 节点 EVM 公钥（以太坊地址）
  string node_ws_addr    = 2; // 节点 WebSocket 地址，供客户端连接
}

message ActivateResponse {
  string app_id               = 1; // hub 分配的节点唯一标识（UUID）
  string hub_public_key       = 2; // hub-server EVM 公钥，节点存入 config.json
}

// --- Heartbeat ---

message HeartbeatRequest {
  string node_public_key = 1;
  string ws_addr         = 2;
}

message HeartbeatResponse {
  bool ok = 1;
}

// --- SignSession ---

message SignSessionRequest {
  // user_credential 格式：base64url({"app_uid":"...","exp":...}) + "." + hex(sig)
  // 由 hub-server 验证签名并提取 app_uid
  string user_credential = 1;
  int64  expiry          = 2; // session_sig 过期时间（Unix 秒）
}

message SignSessionResponse {
  // session_sig 格式：0x + hex(sig)
  // sig = Sign(keccak256(node_public_key \x00 app_uid \x00 expiry), hub_private_key)
  string session_sig = 1;
  string app_uid     = 2; // 从 user_credential 中提取
}

// --- PushNotify ---

message PushNotifyRequest {
  repeated string app_uids = 1;
  string          title    = 2;
  string          body     = 3;
  // 额外数据，JSON 字符串（避免 protobuf 嵌套 map 复杂性）
  string          data_json = 4;
}

message PushNotifyResponse {
  bool ok = 1;
}
```

## 使用方式

**hub-server（gRPC server）引用：**

```bash
go get github.com/langgexyz/open-im-hub-proto@latest
```

```go
import hubv1 "github.com/langgexyz/open-im-hub-proto/hub/v1"

// 实现 HubService server
type hubServer struct {
    hubv1.UnimplementedHubServiceServer
}
```

**open-im-node-server（gRPC client）引用：**

```bash
go get github.com/langgexyz/open-im-hub-proto@latest
```

```go
import hubv1 "github.com/langgexyz/open-im-hub-proto/hub/v1"

// 创建 gRPC client
conn, _ := grpc.Dial(hubAddr, grpc.WithTransportCredentials(insecure.NewCredentials()))
client := hubv1.NewHubServiceClient(conn)
```
